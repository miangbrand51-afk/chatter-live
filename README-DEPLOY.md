# Chatter Live — deployment-ready starter

This is the real-time Chatter app prepared for deployment on Render with a persistent SQLite disk.

## Deploy it

1. Create a GitHub account (if you do not already have one).
2. Create a new **private** GitHub repository named `chatter-live`.
3. Upload all files and folders from this project ZIP to the repository root.
4. Sign in to Render and choose **New → Blueprint**.
5. Connect GitHub and select your `chatter-live` repository.
6. Render reads `render.yaml`. Review the service and disk, then approve deployment.
7. When deployment completes, open the `onrender.com` URL Render gives you.
8. Create two separate accounts (for example, two browsers) and test live messaging.

## Notes
- The Blueprint uses a paid Render Starter web service and a 1 GB persistent disk. Render pricing can change; review the current cost before approving.
- `JWT_SECRET` is generated by Render. Do not share it or put secrets in GitHub.
- This starter stores messages on the server. It is **not end-to-end encrypted** and should not be used for confidential messages.
- Add HTTPS-only production cookie/token hardening, account recovery, abuse reporting, backups, and monitoring before broad public use.
- This app currently supports direct text messages, not calls, media uploads, group chats, or WhatsApp account integration.
